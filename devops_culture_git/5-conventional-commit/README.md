# HolbieBot

HolbieBot est un petit bot de maintenance DevOps écrit en Python.

Il permet d'afficher son état actuel et son niveau d'énergie, de vérifier que l'énergie reste comprise entre 0 et 100, et de simuler le démarrage d'un déploiement.

## Lancer le programme

Depuis le dossier du projet, exécutez :

```bash
python3 devops_bot.py
